# AutoApply Local

一个本地运行的职位筛选、材料生成和网页填表助手。它把可逆的重复工作自动化，把不可逆的“最终提交”放在明确授权之后。

## 第一版能做什么

- 手工粘贴或 CSV 批量导入职位
- 依据你的真实技能、目标岗位、经验、地点和排除词做确定性评分
- 显示匹配证据、缺口和硬性阻断原因
- 从已确认资料生成定制版简历、求职信、常见问题答案和来源映射
- Chrome / Edge 扩展扫描并填写当前申请页面
- 自动跳过附件、密码、人口统计、法律声明等高风险字段
- 检测验证码和未知必填项后停止
- 默认不自动提交；开启后仍需针对当前表单快照进行一次性批准
- 记录职位、材料哈希、批准、提交尝试和结果，防止重复投递

它不会绕过验证码、伪造经历、猜测敏感答案或保证适配所有招聘网站。

## 快速开始

1. 双击 `start.cmd`。
2. 浏览器打开 `http://127.0.0.1:8765` 后，先填写“候选人资料”，尤其是真实工作经历。
3. 在“添加职位”中粘贴职位信息，或导入 `sample-jobs.csv` 格式的 CSV。
4. 查看匹配分数，点击“生成材料”。
5. 按下方步骤安装浏览器扩展并自动填表。

如系统阻止双击脚本，可在此目录打开 PowerShell，运行：

```powershell
python app.py
```

如果双击后窗口一闪而过，请使用 v0.1.1 或更新版本的 `start.cmd`。新版会保留错误窗口，方便直接查看原因。Windows 批处理文件必须使用 CRLF 换行；旧 v0.1 的 LF 换行可能被 `cmd.exe` 解析为语法错误。

## 安装 Chrome / Edge 扩展

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目的 `extension` 文件夹。
4. 打开控制台“设置”，复制本机连接令牌。
5. 点击浏览器工具栏中的 AutoApply 图标，粘贴令牌并连接。
6. 打开申请页面，选择已准备职位，先“扫描”，再“自动填写”。

扩展只在你主动点击时获得当前标签页权限；不会后台浏览其他页面。浏览器安全规则不允许脚本替你选择本地附件，因此简历文件仍需手工上传，扩展会明确标出。

## 最终提交保护

浏览器自动提交默认关闭。建议先保持关闭，逐份检查并手工提交。

若以后开启：

1. 扩展先完成填写并把当前字段快照哈希记录到本机。
2. 你在控制台检查职位、材料和未知字段，然后批准。
3. 扩展重新扫描，只有快照未变化、没有验证码、没有未知必填项、批准未过期且未超过每日上限，才会显示可提交。
4. 点击后还会出现浏览器原生二次确认。
5. 点击发生后先记录为“结果待核对”，不会因为超时而自动重投。

## 本地数据

- SQLite 与访问令牌：`data/`
- 每个职位生成的材料：`materials/`

这两个目录可能包含个人信息，已被 `.gitignore` 排除。不要把它们上传到公共仓库。删除整个 `data` 和 `materials` 目录即可清空本地数据；操作前请自行备份需要保留的材料。

## 测试

```powershell
python -m unittest discover -s tests -v
```

测试覆盖五层反证：

1. 评分、事实来源和硬阻断不变量。
2. 数据库去重、一次性批准与每日上限。
3. 模拟招聘表单的安全填表契约。
4. 提交结果未知时不重试。
5. 日志、附件哈希与本地隐私边界。

## 当前边界与下一步

第一版依赖你导入职位，不进行大规模抓取。下一阶段可以增加特定 ATS 适配器、OpenAI 可选材料改写、邮件确认对账和更严格的 Windows 凭据加密；这些都应在真实小批量验证后再打开。
